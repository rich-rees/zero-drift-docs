# Goldens

Byte-for-byte expectations for the engine's artifacts. A test that compares
against one of these goes red when generated bytes change; that is the point.
**Never regenerate a golden to make a red test pass.** Regenerate only when a
change to the generated bytes is the intended outcome, in its own narrated
commit, and say so in the commit body.

## Files

| Golden | Fixture | Test |
|---|---|---|
| `nextjs-supabase-metadata/` | `test/fixture` | `extractors.test.mjs` (composed and legacy-adapter runs) |
| `agent-index-v0.3.1-nextjs-supabase.md` | `test/fixture` | `viewers.test.mjs` |
| `human-index-bundle-v0.3.1-nextjs-supabase.json` | `test/fixture` | `viewers.test.mjs` — the raw `window.BUNDLE = …;` literal plus a trailing newline |
| `human-index-v1.0-nextjs-supabase.html` | `test/fixture` | `viewers.test.mjs` — the whole page with the two vendor bodies replaced by their placeholders (CR-096) |
| `fastapi-supabase-metadata/`, `fastapi-supabase-graph.json`, `fastapi-supabase-agent-index.md` | `test/fixture-fastapi` | `extractors.test.mjs` (CR-097) |

## Provenance

The `v0.3.1` goldens were captured from engine 0.3.0 (tag `v0.3.1`) by running
that engine's `derive` + `render` on `test/fixture`, before the extractor split
and the viewer registry; reproducing them byte-for-byte is the contract those
refactors met. The `v1.0` / FastAPI goldens were generated at engine 1.0.0 with
the DIO-312 review fixes applied, by the commands below.

## Regenerating

From `packages/zdd-engine`, POSIX shell (Git Bash on Windows). Each block
renders a scratch copy of a fixture — the fixtures themselves stay untouched.

```sh
# Next.js fixture: metadata tree, agent index, BUNDLE literal, full page.
T=$(mktemp -d) && cp -r test/fixture/. "$T"
node bin/zdd-engine.mjs derive --root="$T" && node bin/zdd-engine.mjs render --root="$T"
rm -rf test/golden/nextjs-supabase-metadata && cp -r "$T/zdd/metadata" test/golden/nextjs-supabase-metadata
cp "$T/zdd/agent-index.md" test/golden/agent-index-v0.3.1-nextjs-supabase.md
node -e '
  const fs = require("fs"); const html = fs.readFileSync(process.argv[1] + "/zdd/human-index.html", "utf8");
  fs.writeFileSync("test/golden/human-index-bundle-v0.3.1-nextjs-supabase.json", /window\.BUNDLE = (.*);\n/.exec(html)[1] + "\n");
  let page = html;
  for (const [marker, file] of [["/*__CYTOSCAPE_JS__*/", "src/viewers/cytoscape/vendor/cytoscape.min.js"], ["/*__MARKED_JS__*/", "src/viewers/cytoscape/vendor/marked.min.js"]]) {
    const body = fs.readFileSync(file, "utf8"); const at = page.indexOf(body);
    if (at === -1 || page.indexOf(body, at + 1) !== -1) throw new Error(file + " not inlined exactly once");
    page = page.slice(0, at) + marker + page.slice(at + body.length);
  }
  fs.writeFileSync("test/golden/human-index-v1.0-nextjs-supabase.html", page);
' "$T"
rm -rf "$T"

# FastAPI fixture: metadata tree, graph, agent index.
T=$(mktemp -d) && cp -r test/fixture-fastapi/. "$T"
node bin/zdd-engine.mjs derive --root="$T" && node bin/zdd-engine.mjs render --root="$T"
rm -rf test/golden/fastapi-supabase-metadata && cp -r "$T/zdd/metadata" test/golden/fastapi-supabase-metadata
cp "$T/zdd/graph.json" test/golden/fastapi-supabase-graph.json
cp "$T/zdd/agent-index.md" test/golden/fastapi-supabase-agent-index.md
rm -rf "$T"
```

Then `node --test "test/*.test.mjs"` must be green, and the diff under
`test/golden/` is reviewed line by line before it is committed.
